# Foreman 홍보 영상 — 콘셉트

40초 · 1920×1080 · 30fps · 나레이션 없음 · 자막(ko/en 번인) · 합성 음악(직접 생성, numpy)

브랜드 문서: `Foreman/docs/design/v3/BRAND-v3.md` (v3, 2026-10-22). 검정·흰색·회색뿐, 상태는 색이 아니라 모양(● 당신 차례, ▲ 위험, ◌ 실행 중, ✓ 완료, — 대기), 둥근 카드 격자 대신 헤어라인과 1px 규칙선, 세리프 없음, Pretendard + JetBrains Mono, 감속형 모션 `cubic-bezier(0.2, 0, 0, 1)`. 심볼은 평평한 선 위로 한 번 솟는 "펄스".

v2(코발트·라임, Γ+커서 심볼) 기준으로 처음 만든 콘셉트 "켜진 커서 하나"를 v3에 맞게 바꿨다: 라임 커서 블록 → "당신 차례" 표지 ●, 엔드카드의 커서 조립 → 펄스 선 긋기.

## 고른 콘셉트: A. 켜진 표지 하나 (v3)

- 화면마다 강조는 한 곳: "당신 차례" 표지 ●(채운 원). 0.6→1.0으로 한 번 커지고 멈춘다(BRAND-v3 §7).
- 제품 화면은 디자인 시스템의 v3 시안 PNG만 쓴다. 코드로는 모션 레이어(●, 세션 목록, 한도 열, 경로 선, 로고 긋기, 자막)만 그린다.
- 한글은 자막이 아니라 화면의 주 카피로 쓴다(Pretendard 600, 자간 −2%). 명령·경로·세션 이름만 JetBrains Mono.
- 엔드카드: 펄스 마크의 평평한 선을 긋고 한 번 솟은 뒤 워드마크. "일하는 동안은 조용하다가, 당신 차례에만 한 번 솟는다"는 심볼의 뜻을 그대로 움직임으로.
