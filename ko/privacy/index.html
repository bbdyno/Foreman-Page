개인정보 처리방침

Foreman은 개발자가 운영하는 서버가 없고, 개발자는 이용자의 개인정보를 수집하지 않습니다.

요약

Foreman 앱이 다루는 데이터는 이용자의 기기와 이용자의 iCloud에만 저장됩니다. 개발자는 그 데이터를 받거나 볼 수 없습니다.

  • 회원 가입이 없고, 이름·이메일·전화번호를 받지 않습니다.
  • 광고 식별자, 분석 도구, 추적 SDK를 쓰지 않습니다.
  • 세션 내용은 기기 사이에서 종단간 암호화되어 오갑니다.

개발자가 수집하는 정보

없습니다. 개발자는 중계 서버, 로그 서버, 계정 서버를 운영하지 않으므로 이용자의 정보가 개발자에게 전송되지 않습니다.

앱이 다루는 데이터와 저장 위치

앱이 동작하려면 아래 데이터가 필요합니다. 모두 이용자가 관리하는 곳에만 저장됩니다.

  • 세션 출력과 기록(에이전트의 터미널 출력, 대화, 변경 내용): 에이전트가 도는 이용자의 Mac. 기기 사이를 직접 연결할 수 없을 때는 이용자 iCloud의 CloudKit 개인 데이터베이스를 거칩니다.
  • 승인 요청과 질문: 이용자의 Mac, 이용자의 기기, 이용자 iCloud의 CloudKit 개인 데이터베이스.
  • 페어링 정보와 API 키: 이용자 기기의 키체인. 에이전트 API 키는 에이전트가 도는 Mac의 키체인에만 둡니다.
  • 설정과 승인 규칙: 이용자의 기기와 이용자 iCloud.

iCloud에 저장된 데이터는 Apple의 iCloud 이용 약관과 개인정보 처리방침을 따릅니다.

외부 서비스와의 통신

  • Apple: iCloud(CloudKit), 푸시 알림, App Store 결제를 이용합니다. 알림은 이용자 iCloud에 등록한 구독을 통해 Apple이 직접 보냅니다.
  • 공개 STUN 서버(stun.cloudflare.com, stun.l.google.com): 기기 사이 직접 연결 경로를 찾을 때 이용자의 공인 IP 주소를 확인하는 데만 씁니다. 세션 내용은 보내지 않습니다. 각 서버 운영자의 정책이 적용됩니다.
  • 에이전트 제공자: Claude Code, Codex, Gemini CLI 같은 에이전트는 이용자의 Mac에서 이용자가 직접 실행하며, 각 제공자의 약관과 개인정보 처리방침에 따라 해당 서비스와 통신합니다. Foreman은 에이전트의 통신에 끼어들거나 대신 데이터를 보내지 않습니다.

크래시 리포트와 진단 정보

앱 안에 별도의 크래시 수집 도구를 넣지 않습니다. 개발자가 받는 크래시 정보는 App Store(Android 버전은 Google Play)가 기본으로 제공하는 범위에 한하며, 이용자가 기기 설정에서 개발자와 공유하기로 동의한 경우에만 Apple 또는 Google을 통해 전달됩니다. 이 정보에는 이용자를 식별하는 정보가 포함되지 않습니다.

결제

구독 결제는 App Store가 처리합니다. 개발자는 결제 수단이나 청구 정보를 받지 않습니다. Mac 앱은 App Store가 서명한 구독 내역을 이용자 iCloud에서 읽어 구독 상태를 확인합니다.

보관과 삭제

데이터는 이용자가 지울 때까지 이용자의 기기와 iCloud에 남습니다. Free 요금제의 세션 기록은 7일이 지나면 자동으로 지워집니다. 앱을 삭제하면 해당 기기의 데이터가 지워지고, iCloud에 남은 데이터는 iPhone 설정 앱에서 내 이름, [iCloud], [계정 저장 공간 관리] 순으로 들어가 Foreman을 골라 지울 수 있습니다. Mac의 세션 기록은 Mac 앱 설정에서 지웁니다.

이 웹사이트

이 웹사이트는 GitHub Pages에서 제공됩니다. 쿠키, 분석 도구, 외부 글꼴 서버를 쓰지 않습니다. GitHub는 서비스 운영을 위해 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.

아동

Foreman은 개발자를 위한 도구이며 만 14세 미만 아동을 대상으로 하지 않습니다. 개발자는 아동의 개인정보를 포함해 어떤 개인정보도 수집하지 않습니다.

방침의 변경

이 방침이 바뀌면 이 페이지에 새 내용과 시행일을 게시합니다. 변경 이력은 GitHub 저장소에서 볼 수 있습니다.

문의

개인정보에 관한 문의는 GitHub Issues로 남겨 주세요. 공개 이슈에는 개인정보를 적지 마세요.
