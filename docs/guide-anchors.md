# 가이드 앵커 목록

앱의 도움말 링크가 가리키는 고정 앵커입니다. 이 ID는 바꾸지 않습니다. 절을 고쳐 쓰더라도 ID는 그대로 두고, 제목만 바꿉니다.

- 한국어: `https://bbdyno.github.io/Foreman-Page/ko/guide/#<id>`
- 영어: `https://bbdyno.github.io/Foreman-Page/guide/#<id>`
- 한국어와 영어 페이지의 ID는 같습니다. 앱은 기기 언어가 한국어면 `/ko/guide/`, 아니면 `/guide/`를 엽니다.
- 원본: `tools/site/guide-ko.mjs`, `tools/site/guide-en.mjs`. 빌드할 때 두 페이지의 ID가 같은지 확인합니다.
- 가이드에 쓴 시험 측정 수치의 출처는 [guide-sources.md](guide-sources.md)에 있습니다.

## 예약한 앵커 (페이지에 아직 없음)

아래 기능이 사용자에게 쓸 수 있는 형태로 main에 들어오면 해당 절을 채우면서 이 ID를 씁니다. 사이트 화면에는 예약 표시를 두지 않고, 이 목록에만 적어 둡니다. 앱은 이 ID로 링크를 미리 걸어도 되지만, 절이 채워지기 전에는 페이지 맨 위가 열립니다.

| ID | 들어갈 내용 | 들어갈 자리 | 지금 비워 둔 이유 (main b427465) |
| --- | --- | --- | --- |
| `cloud-google-drive` | Google 드라이브 연결 | `cloud` 소절 | 호스트는 Google 로그인을 지원하지만, 이를 쓰는 앱(Android·Windows)에 클라우드 경로가 아직 없습니다 |
| `connection-android-windows` | Android·Windows 앱의 집 밖 연결 | `connection` 소절 | Flutter 앱은 아직 LAN으로만 연결합니다 |
| `pro-pipeline` | 파이프라인 | `pro` 소절 | 앱에서 템플릿을 만들 수 없고 호스트에 기본 템플릿이 없어 사용자가 쓸 방법이 없습니다 |
| `agents-import` | 지난 세션 가져오기 | `agents` 소절 | 호스트 프로토콜만 있고 앱 UI가 없습니다 |
| `pro-android-windows` | Android·Windows 앱의 Pro 기능(페일오버·레이스 등) | `pro` 소절 | Flutter 앱의 Pro 기능은 화면만 있고 호스트로 보내지 않습니다. Windows 결제는 스토어 등록 전입니다 |

예약 ID를 페이지에 쓰기 시작하면 위 표에서 지우고 "지금 페이지에 있는 앵커" 표로 옮깁니다.
