Foreman은 내 컴퓨터에서 도는 코딩 에이전트(Claude Code, Codex, Gemini CLI, OpenCode)를 iPhone, iPad, Apple Watch, Mac에서 보고 승인하는 앱입니다. 에이전트가 명령을 실행해도 되는지 묻거나 질문하면 바로 알림이 오고, 그 자리에서 답할 수 있습니다.

승인과 질문
- 모든 컴퓨터의 승인 요청과 질문이 승인 탭 한곳에 모입니다.
- 되돌릴 수 있는 요청은 알림, 잠금화면, 위젯, Apple Watch에서 바로 허용합니다.
- 운영 데이터베이스 변경이나 강제 푸시처럼 되돌릴 수 없는 작업은 앱 안에서 Face ID로 확인해야만 허용됩니다.
- 질문에는 선택지 버튼이나 직접 입력으로 답합니다.

세션
- 대화, 터미널, 변경 세 가지 보기로 세션을 따라갑니다.
- 호스트의 터미널 화면을 그대로 보고 입력합니다.
- 새 세션을 시작할 때 git worktree로 격리해 원래 작업 폴더를 건드리지 않습니다.
- iPad와 Mac의 관제 그리드에서 여러 세션을 한 화면에 펼칩니다.
- 터미널을 닫아도 세션은 호스트에서 계속 돌고, 앱은 언제든 다시 붙습니다.

연결과 보안
- 에이전트가 도는 Mac이나 Windows PC에 Foreman Host를 설치하고 QR 코드로 페어링합니다. 양쪽 화면의 여섯 자리 숫자로 서로를 확인합니다.
- 모든 연결은 Noise 프로토콜로 처음부터 끝까지 암호화됩니다.
- 호스트를 내 iCloud 계정에 연결하면 앱이 꺼져 있어도 승인 요청이 알림으로 오고, 집 밖에서도 호스트에 연결됩니다.
- 개발자가 운영하는 서버가 없습니다. 세션 내용은 내 컴퓨터, 내 기기, 내 iCloud 계정 사이에서만 오갑니다.

Foreman Pro
- 에이전트 종류 제한 없음(Free는 2종)
- 승인 요청에서 자동 허용 규칙 만들기
- 한도 페일오버: 한 에이전트가 사용 한도에 닿으면 다음 에이전트가 이어받습니다
- 다른 에이전트로 넘기기, 두 에이전트 레이스와 비교
- 한도 리셋 후 자동 재개, 아침 브리핑
- 구독은 페어링한 모든 호스트에 적용됩니다.

Foreman Pro는 월간 또는 연간 자동 갱신 구독입니다. 결제는 구매 확인 시 Apple 계정으로 청구되며, 현재 기간이 끝나기 24시간 전까지 해지하지 않으면 자동으로 갱신됩니다. 구독 관리와 해지는 App Store 계정 설정에서 할 수 있습니다.
